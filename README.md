# 🎮 BRAWLER GENERATOR

Um gerador incrível de Brawlers para Brawl Stars! Cada clique gera um Brawler único com aparência visual, poderes e stats aleatórios.

## ✨ Recursos

- 🎨 **Imagens Aleatórias** - Cada Brawler tem uma aparência visual única gerada por código
- 📝 **Nomes Únicos** - Nomes aleatórios e incríveis
- ⚔️ **Poderes Especiais** - Três tipos diferentes de habilidades
- ❤️ **Stats Variados** - Vida, Ataque, Defesa e Velocidade aleatórias
- 🎭 **Tipos Diferentes** - Tanque, Atirador, Suporte, Assassino e mais!
- 🎨 **Design Responsivo** - Funciona perfeitamente em celular e desktop

## 🚀 Como Usar

1. Abra o arquivo `index.html` no seu navegador
2. Clique no botão **"⚡ GERAR NOVO BRAWLER ⚡"**
3. Veja seu Brawler único aparecer com todas as suas características!
4. Continue gerando novos Brawlers

## 📁 Estrutura dos Arquivos

```
brawler-generator/
├── index.html      # Estrutura da página
├── style.css       # Estilos bonitos e responsivos
├── script.js       # Lógica de geração aleatória
└── README.md       # Este arquivo
```

## 🎨 Características Técnicas

- Canvas 2D para desenho dos Brawlers
- Cores aleatórias em gradientes
- Sistema de geração procedural de nomes
- Banco de dados com 35+ nomes diferentes
- Mais de 50 habilidades diferentes
- Stats dinâmicos baseados em tipos de Brawlers
- Animações suaves e efeitos visuais

## 💡 Como Funciona

O gerador funciona através de:

1. **Seleção Aleatória** - Escolhe nome, tipo, cores e habilidades de bancos de dados
2. **Canvas Drawing** - Desenha o Brawler usando primitivas 2D
3. **Cálculo de Stats** - Gera vida, ataque, defesa e velocidade aleatórias
4. **Exibição** - Mostra o Brawler com todas as informações

## 🔄 Gerar Novos Brawlers

Apenas clique no botão principal para gerar quantos Brawlers quiser! Cada geração é completamente aleatória.
